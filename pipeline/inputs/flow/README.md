# Pasta de Clipes Externos (Google VideoFX / Veo 2) 🎬

Esta pasta é monitorada automaticamente pelo **AutoPublisher Pro**.

### Como Utilizar:
1. No painel web (**Estúdio Veo 2**), gere os prompts e áudio para o roteiro desejado.
2. Abra o [Google VideoFX](https://labs.google/fx/tools/video-fx), cole os prompts em formato **9:16 (Vertical)** e faça o download dos clipes.
3. Salve os vídeos baixados nesta pasta (`pipeline/inputs/flow/`) com os nomes:
   * `scene_1.mp4` (ou `take_1.mp4`)
   * `scene_2.mp4` (ou `take_2.mp4`)
   * `scene_3.mp4` ...
4. No Dashboard, o sistema detectará automaticamente os clipes e o botão mudará para **"Montar Vídeo com Clipes Veo"**.
5. Clique em montar e o sistema fará a sincronização perfeita da voz neural, legendas dinâmicas em karaokê e música de fundo!

> *Se esta pasta estiver vazia, o sistema opera automaticamente no modo 100% autônomo com vídeos e fotos de estoque animados pelo FFmpeg.*
